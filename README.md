## 🚧 O que estou construindo agora

### 🏋️ ApexLift

Uma plataforma para acompanhamento e evolução de treinos.

O projeto começou como uma ideia de aplicativo fitness e acabou se tornando um dos projetos em que mais tenho aprendido sobre desenvolvimento de software.

Ele é dividido entre uma **API REST desenvolvida em Java com Spring Boot** e um aplicativo Android desenvolvido em **Kotlin**.

### Backend

`Java` `Spring Boot` `Spring Security` `JWT` `Spring Data JPA` `PostgreSQL`

No backend estou trabalhando com:

- autenticação e autorização;
- usuários;
- exercícios;
- fichas de treino;
- sessões de treino;
- histórico de evolução;
- validações;
- tratamento de exceções;
- testes automatizados.

### Android

`Kotlin` `Jetpack Compose` `Retrofit` `Room`

A aplicação Android consome a API e também trabalha com persistência local.

🔗 [ApexLift API](https://github.com/RuanSilva23/ApexLift-api)

🔗 [ApexLift Android](https://github.com/RuanSilva23/ApexLift-android)

### 🍺 Gerenciador de Depósito de Bebidas

Esse projeto nasceu da vontade de transformar um problema de negócio em software.

A ideia é desenvolver um sistema voltado para a organização das operações de um depósito de bebidas.

Atualmente trabalho com modelagens relacionadas a:

- produtos;
- fornecedores;
- compras;
- clientes;
- pedidos;
- estoque.

Durante o desenvolvimento venho praticando principalmente modelagem de domínio, regras de negócio e separação das responsabilidades da aplicação.

### Stack

`Java` `Spring Boot` `Spring Data JPA` `PostgreSQL`

🔗 [Ver projeto](https://github.com/RuanSilva23/depositobebidas)
